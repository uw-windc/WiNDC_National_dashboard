# WiNDC National Dashboard

Caution: This is a work in progress and incomplete. It is intended as a proof of concept for a national dashboard for the WiNDC project. 


To use this dashboard, follow these steps:

1. Clone the repository to your local machine.
2. Open the project in VSCode
3. Activate the local environment and instantiate the required dependencies.
4. In the REPL run 
 ```julia
 using GenieFramework; Genie.loadapp(); up()
```
5. Open your web browser and navigate to `http://localhost:8000` to view the dashboard.
